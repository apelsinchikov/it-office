# IT-Office

Idle-tycoon про IT-отдел: вы директор компании и растите один стол техподдержки в большой IT-департамент. Игра запускается как Telegram Mini App.

- Дизайн-документ: [docs/GDD.md](docs/GDD.md)
- Игра в браузере: https://apelsinchikov.github.io/it-office/

## Технологии

- TypeScript + Vite + PixiJS 8 (сцена), HTML поверх сцены (интерфейс)
- GitHub Pages — хостинг, выкладка через GitHub Actions при каждом push в `main`
- Telegram Mini App — запуск через бота
- Telegram CloudStorage — сохранение прогресса (рейтинг и сервер — после MVP)

## Запуск у себя

```bash
npm install
npm run dev
```

Откроется http://localhost:5173/it-office/

`npm test` — тесты экономики, `npm run build` — сборка. Адрес с `?debug` даёт доступ к игре из консоли браузера (`__game`, `__hud`, `__office`).

## Что внутри (1.0.0)

- 5 отделов по 6 сотрудников, руководители, мебель, зона отдыха, туалет, ходячие сотрудники и фразы
- тикеты, «Аврал», офлайн-доход до 2 ч, реорганизация, Гранты и магазин улучшений
- 4 офиса по кругу: стартап, банк, игровая студия, космос
- обучение, задания, 22 достижения, коллекция фраз, звуки, русский и английский
- события: Новый год, День сисадмина, хакатон
- сохранение на устройстве и в Telegram CloudStorage

## Структура

- `src/game` — правила и экономика без графики (тестируются)
- `src/scene` — офис на PixiJS: персонажи, мебель, камера
- `src/ui` — интерфейс поверх сцены
- `sim` — симулятор игроков, результаты в [sim/README.md](sim/README.md)
