# Прогресс внутри офиса

## Purpose

Что и в каком порядке открывается в одном забеге (`src/game/config.ts`, `src/game/game.ts`).

## Requirements

### Requirement: Отделы
Отделов MUST быть 5, номера по порядку открытия: 0 сисадмины, 1 поддержка, 2 аналитики, 3 разработка, 4 тестирование. В каждом до 6 мест.
Мебель: сисадмины — пост, ящик с инструментами, стул, лампа + кружка; поддержка — стол, стул, телефон + цветок, кружка;
аналитики — стол, стул, телефон, монитор + цветок; разработка — стол, стул, монитор, клавиатура + цветок; тестирование — стол, стул, монитор, клавиатура, мышь + цветок.

### Requirement: Порядок открытия
Комнаты MUST открываться строго по `SEQUENCE`: сисадмины (открыты со старта, первый сотрудник 1-го уровня) → поддержка → директор IT → зона отдыха → аналитики → туалет → разработка → тестирование.
Следующая комната доступна, только когда открыта предыдущая. Директор, отдых и туалет покупаются за монеты.

#### Scenario: рано
- GIVEN поддержка не открыта
- WHEN игрок открывает панель директора
- THEN видит «Сначала откройте «Поддержка»» и неактивную кнопку

#### Scenario: открытие
- GIVEN поддержка открыта и монет хватает
- WHEN игрок жмёт «Открыть» у директора
- THEN кабинет открыт, приходит событие `{type:'room', id:'director'}`, появляется кнопка «Аврал»

### Requirement: Что даёт каждая комната
- Директор IT MUST открывать «Аврал» и задания директора (см. director).
- Зона отдыха MUST открывать покупки кофемашины, холодильника и игр и места для прохожих.
- Туалет MUST давать +3% ко всему офису и место для прохожих.

### Requirement: Реорганизация закрывает всё
Реорганизация MUST сбрасывать забег: открыты только сисадмины, комнаты закрыты, монеты = стартовый капитал.

### Requirement: Подсказка «Быстрее окупится»
Советник (`advisor.ts`) MUST выбирать покупку с наименьшим временем окупаемости (цена / прирост дохода в секунду) среди уровней, найма, мебели, руководителей, отделов, комнат и зоны отдыха. На кнопке этой покупки — значок «Быстрее окупится», в панели — пояснение значка.
