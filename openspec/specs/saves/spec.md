# Сохранения

## Purpose

`src/game/state.ts`, `src/game/save.ts`, вызовы в `src/main.ts`. Сервера нет.

## Requirements

### Requirement: Где хранится
Состояние (схема v3) MUST сохраняться в localStorage (`it-office.save.v2`) каждые 5 с, при сворачивании и закрытии, и раз в 45 с в Telegram CloudStorage частями по 4096 символов.
При запуске берётся более продвинутое из двух; если облако дальше — локальное перезаписывается и страница перезагружается.

### Requirement: Миграции
`normalize` MUST: v1 → новая игра с монетами и общим заработком; v2 → забег заново (новый порядок отделов и экономика), Гранты, магазин, достижения, фразы, задания остаются; улучшения отделов в магазине переезжают по таблице старый→новый `[1, 3, 4, 2, 0]`; неизвестная версия → новая игра.

#### Scenario: v2
- GIVEN сохранение v2 с `speed0` (старая поддержка)
- WHEN оно загружается
- THEN становится `speed1` (поддержка теперь отдел 1), монеты забега 0

### Requirement: Сброс
Сброс в настройках MUST требовать второго нажатия и стирать обе копии.
