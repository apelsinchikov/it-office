# Симулятор игроков

Гоняет настоящий игровой код (`src/game/*`) без графики: виртуальный игрок заходит в игру по расписанию, покупает, ловит тикеты, жмёт «Аврал», забирает офлайн-доход, делает реорганизации и меняет компании.

```bash
npx tsx sim/run.ts C 400 4        # профиль, макс. дней, сколько компаний пройти
NOQUESTS=1 npx tsx sim/run.ts A   # без заданий — чтобы увидеть их вклад
npx tsx sim/run.ts C 400 8 1000   # 4-й аргумент — шаг цены компаний (в игре 100)
```

## Профили

| | Как играет | Ловит тикеты | Особенность |
|---|---|---|---|
| A | 1 заход в день × 3 мин | 90% | покупает по «Выгодно» с ошибками |
| B | 4 × 3 мин | 90% | |
| C | 8 × 5 мин | 85% | |
| D | 6 × 1 ч | 80% | |
| E | 4 × 3 ч | 75% | |
| F | 1 × 16 ч подряд | 70% | |
| BOT | 24/7, идеально | 100% | ждёт самую окупаемую покупку, как модель в GDD |

## Результаты (версия 1.0.0)

Дни до «всё куплено» в первом офисе и до конца четвёртой компании:

| Профиль | 1-й офис | GDD-ожидание | 4 компании | Часов в игре (1-й офис) |
|---|---|---|---|---|
| A 1×3 мин | 174 | ~300 | 409 | 20 |
| B 4×3 мин | 47 | ~75 | 105 | 21 |
| C 8×5 мин | 23 | ~37 | 56 | 37 |
| D 6×1 ч | 17 | ~24 | 36 | 216 |
| E 4×3 ч | 18 | ~19 | 32 | 384 |
| F 16 ч | 19 | ~16 | 36 | 576 |
| BOT | 6,8 | 6,8 (модель) | 13 | 163 |

Выводы:

- Движок совпадает с моделью из GDD: BOT проходит первый офис за 6,8 дня, 17 реорганизаций, ~424 «часа дохода» против 429 в расчёте.
- Короткие заходы (A–C) идут быстрее расчёта: тикеты, «Аврал» и задания дают больше, чем закладывалось. Для казуального игрока это хорошо — первый офис за 3–6 недель вместо 1,5–10 месяцев.
- Длинные сессии (D–F) почти не выигрывают у коротких: игрок «тратит всё сразу» и не копит на выгодное. Это предусмотрено — мягкий потолок, чтобы игра не проходилась за выходные. Подсказка «Выгодно» в панели отдела сокращает разрыв.
- Задания ускоряют A на ~15%, C на ~4% (цель GDD — 10–15%).
- Шаг цены компаний ×1000 из первой версии GDD делал 2-ю компанию стеной (C: +60 дней). Поставлен ×100: каждая следующая компания идёт ~8–30 дней у C.

Компании для C (8 подряд, шаг ×100): 21,7 → 31,6 → 42,7 → 58,3 → 114,4 → 149,4 → 187,4 → 210,3 дня.
